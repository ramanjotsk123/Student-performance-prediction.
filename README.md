# Student Performance Prediction

## Project Overview
A Python machine-learning project designed to predict
students' final mathematics grades using selected
study-related and personal features.

## Objective
Explore how student-related information can be used
to estimate final academic performance.

## Technologies
- Python
- Pandas
- scikit-learn
- Random Forest Regression

## Machine Learning Workflow
1. Load and inspect the dataset.
2. Separate features and target grades.
3. Preprocess categorical variables.
4. Split the data into training and testing sets.
5. Train a Random Forest regression model.
6. Evaluate predictions using MAE, RMSE and R-squared.

## Dataset
UCI Student Performance Dataset:
https://archive.ics.uci.edu/dataset/320/student-performance

The project uses the mathematics dataset and excludes
the first- and second-period grades from its input features.

## Limitations
The dataset represents two Portuguese schools.
Results may not generalize to other student populations.
